# 수업 시작하기

Claude Code에서 `/sparker-camp:start`를 입력하세요. 몇 주차 수업 또는 과제인지 고르면 준비 상태를 확인하고 실습으로 이어집니다. 같은 활동은 같은 대화에서 이어서 할 수 있어요.

처음 시작할 때 대화 기록 보관·전송 안내를 확인합니다. 시작한 이후의 이 대화와 함께 실행한 보조 작업의 대화 기록이 운영진에게 전달됩니다. 계정 연결 전에는 기록이 이 컴퓨터에 보관됩니다.

기록은 델타 운영진 Xavier·Sung·Zoon 세 명이 열람하고, 캠프가 끝난 뒤에도 개선·분석을 위해 보관합니다. HR에는 운영진이 요약을 전달하며 특정 대화만 골라 삭제하는 기능은 제공하지 않습니다.

## 계정 연결

1. [참가자 앱](https://leaderboard-production-eac2.up.railway.app)에 로그인하고 **내 계정·설정 → 캠프 대화 기록 연결**을 여세요.
2. 시작 안내에서 제공하는 연결 명령을 **별도 터미널**에서 실행하세요.
3. 터미널에 연결 코드를 입력하세요. 코드는 대화창에 붙여 넣지 마세요.
4. Claude Code로 돌아와 이어서 진행하세요.

앱이 열리지 않거나 연결 메뉴를 찾지 못하면 운영진에게 도움을 요청하세요. 연결을 기다리는 동안에도 실습은 계속할 수 있어요.

## 기록 상태

- **계정 연결 필요:** 아직 기록을 보낼 계정이 연결되지 않았어요.
- **전송 대기:** 보관한 기록 중 전송을 기다리는 부분이 있어요.
- **수신 확인 전:** 연결 정보는 저장돼 있지만 이 대화의 기록 수신은 아직 확인되지 않았어요.
- **수신 확인:** 이 대화에서 전송한 기록의 서버 수신을 확인했어요. 새로 생긴 기록은 다음 전송을 기다릴 수 있어요.
- **확인 필요:** 기록 일부를 보관했는지 확인이 필요해요. 운영진에게 도움을 요청하세요.

이 표시는 대화 기록 상태입니다. 기획서 과제 제출 완료를 뜻하지 않아요. 다른 주차나 수업·과제로 바꿀 때는 현재 진행 내용을 저장한 뒤 `/clear`로 새 대화를 열고 다시 시작하세요.
